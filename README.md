# Manual Testing and Quality Assurance Analysis for E-Commerce Website

## Project Overview

This project focuses on Manual Testing and Quality Assurance analysis of an E-Commerce web application using structured testing methodologies.

The testing process included:

* Functional Testing
* UI Testing
* Regression Testing
* Validation Testing
* Bug Reporting

## Website Tested

SauceDemo Testing Website:
https://www.saucedemo.com/

## Tools Used

* Microsoft Excel
* Manual Testing Techniques
* GitHub
* VS Code

## Test Scenarios Covered

* Login Functionality
* Invalid Login Validation
* Add to Cart
* Remove from Cart
* Checkout Process
* Logout Functionality

## Bug Reporting

Identified and documented multiple UI and functional issues including:

* Error message alignment issues
* Cart update delay
* Form validation problems
* Mobile responsiveness issues
