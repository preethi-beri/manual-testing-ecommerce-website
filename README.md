# Automated and Manual Testing Framework for E-Commerce Website using Selenium & Python

## Project Overview

This project demonstrates Manual Testing and QA Automation workflows for an E-Commerce web application using Selenium WebDriver and Python.

The project includes:

* Selenium Automation Testing
* Functional Testing
* Manual Test Case Documentation
* Bug Reporting & Validation
* GitHub Pages Deployment

## Live Project Website

https://preethi-beri.github.io/manual-testing-ecommerce-website/

## Technologies Used

* Python
* Selenium WebDriver
* ChromeDriver Manager
* VS Code
* GitHub Pages
* Manual Testing Methodologies

## Automation Testing Features

Implemented Selenium WebDriver automation scripts for:

* Login Validation Testing
* Add to Cart Validation
* Logout Functionality Testing
* Automated Browser Testing
* Functional Workflow Validation

## Automation Scripts

* login_test.py
* cart_test.py

The project also includes:
